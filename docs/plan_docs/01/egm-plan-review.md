# 요구사항과 검증 기준

Cycle-Stem: egm-plan-review
Document-Language: ko
Done-Criteria-Revision: 2

확정 요구: #42의 선택형 계획 검토와 기존 승인 체계 유지. 구현 선택: 별도 CLI와 목적별 runner 계약, 설정은 `enabled`/`levels` 두 키, timeout/bytes는 CLI 옵션이다. 기본 300초/1MiB는 입력 폭주 제한이며 비용 보장이 아니다.

## 인수 기준

| ID | 관찰 가능한 결과 |
| --- | --- |
| E01 | OFF이면 없는 입력/host를 조회하지 않음; 제외 위험이면 source/peer 미조회 |
| E02 | 프로필 phase glob에 맞는 00/01/02 또는 Fast00; 동일 basename/stem/language; UTF-8(BOM 허용), 일반 파일, 실경로 중복 제거, plan 저장소 내부; source는 명시 경로만 |
| E03 | `require_controls` 호출 전 검사; unknown version은 통제 옵션 시도하되 무통제 fallback 없음; 기존 호출 인자 기본값 불변 |
| E04 | 입력 SHA256·bytes·원문/부분 결과·사용량/통제/미확인 범위; 저장 경로는 `.sage/plan-reviews/`; 덮어쓰기 금지; 변경 시 STALE; 미측정 null |
| E05 | 표준/Fast 모두 구현 승인 전에 1회; 지적 반영/보류/반박과 이유는 기존02; 실패 시 사람 선택; 자동 재호출 없음 |
| E06 | 실제 비용 없는 fake CLI 경계 검사, 기존 Phase05·프로필·언어·설치 회귀, wheel 소비 검증 |
| E07 | 실제 CLI/model 성공을 fake 테스트와 구분; 독립 리뷰 대상 고정과 사용량 보존 |
| E08 | 사전에 정답을 고정한 실제 모델 시험: 원천과 계획의 충돌, 근거 없는 필수요구, 누락·미결정, 올바른 요구를 결함으로 오인하지 않는 대조, 원천 속 지시를 실행 권한으로 오인하지 않는 대표 사례 |
| E09 | 실제 양 호스트의 새 세션과 부모 전용 canary 미전달·출력·사용량·통제 관측. 프로젝트/사용자 지침파일의 완전 격리로 해석하지 않음 |
| E10 | 후보 wheel clean 설치와 별도로 기존 설치를 갱신하고 사용자 프로필·관련 설정 보존을 대표 확인 |
| E11 | macOS/Linux 일반 회귀와 Windows 대표 CLI/process/설치 확인. 모든 host×OS×설치 조합의 전수 시험은 요구하지 않음 |
| E12 | 계획 검토 전후 생산소스·의존성·실제 index·Phase05 감사 불변. 허용된 scratch와 결과 파일 생성은 별도로 식별 |

COMPLETE는 프로세스 실행 완료이며 계획 승인/PASS가 아니다. 원천이 없으면 자족성만 검토하고 근거 대조는 미확인이다. 결과 공유 시 명시 입력과 출력의 공개 범위를 확인한다.
