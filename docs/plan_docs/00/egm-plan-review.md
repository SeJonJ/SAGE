## 1. 배경과 권한

구현 전에 계획과 명시한 원천을 새 맥락에서 대조하여 누락·추정의 요구 승격·미결 결정·과설계를 찾는다. 이슈 #42의 범위만 개발한다. 개발 착수는 승인되었으며 commit/push/PR/배포는 별도다. SAGE 엔진 개발이므로 00–06 형식만 사용하고 개발 중인 자체 gate·review-loop를 승인 권위로 사용하지 않는다.

## 2. 기준과 재사용

기준 v1.3.8 (`8e38454`). 기존 `peer_process`의 scratch 실행·통제·실패·사용량 수집과 cycle/language/risk/Fast 문서 해석기를 재사용한다. Phase05 고수준 실행기는 사용하지 않는다.

## 3. 범위와 영향

기본 OFF, L2/L3 선택형, 표준 00/01/02와 Fast 합본00, 같은 호스트의 새 프로세스 1회, 명시 입력 스냅샷, 결과 직접 저장, 사람 처분이다. Phase04/05/06과 승인 계약은 유지한다. 플러그인 설치·다단계 EGM·반복·자동 수정·새 gate·tree fingerprint 수정은 제외한다.

## 4. 위험과 검증

공통 runner 회귀, 잘못된 입력 결속, 추가 탐색, 저장 실패, 사용량 누락을 확인한다. 입력 bytes/timeout은 hard token 상한이 아니다. 실제 모델 검증과 독립 Phase05에는 실행 전 별도 수치 예산을 확정한다. 미실행은 NOT_TESTED로 남긴다.

2026-11-18 사용자 결정: 이번 추가 실행은 신규 입력+출력 합계 150,000토큰, 최대 3라운드다. 캐시와 관측 과금은 별도 기록하며 사용량을 확인할 수 없으면 중단한다. 이전 설계 리뷰 사용량은 이번 한도와 분리한다. 사후 계측이므로 실시간 hard cap/과금액 보장은 아니다. 독립 L3는 5개 렌즈(정확성·보안·동시성·컨벤션·수명주기) 각 1명, 반대 호스트 peer 1명, 라운드당 전체 지적을 각각 판단하는 반박자 2명으로 수행한다. 새 맥락과 고정 입력을 사용하며 자체 SAGE 승인 명령은 호출하지 않는다.
